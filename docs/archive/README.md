# Historical documentation archive

These files are **unchanged snapshots** of the pre-restructuring `master` documentation at the merged 3.0.12 baseline. They retain historical milestone scope, narrative and mathematical explanations, including superseded APIs. `README-3.0.12.md` preserves the original 431-line README, including its obsolete architecture drawing, for attribution and historical traceability.

Do **not** treat these snapshots as the current API. Start instead from the [canonical documentation index](../index.md), [current reference](../index.md#module-sub-papers) and [roadmap](../roadmap.md). Older relative links in archived documents may point to pre-migration locations; the compatibility pointers at former `docs/*.md` URLs redirect to the current or archived material. The archive is deliberately excluded from current-document link and Markdown style enforcement so the original text can be preserved exactly.

When comparing scientific claims across milestones, cite the specific original revision or this archive and make any change in assumptions explicit.
